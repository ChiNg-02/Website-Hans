Tết Yêu Thương

Cấu trúc thư mục để upload ảnh theo từng năm:
- cover/ : ảnh bìa cho trang dự án
- 2021/ : ảnh hoạt động năm 2021
- 2022/ : ảnh hoạt động năm 2022
- 2023/ : ảnh hoạt động năm 2023
- 2024/ : ảnh hoạt động năm 2024

Bạn có thể đặt tên file theo ý bạn, ví dụ:
- cover.jpg
- 2021-01.jpg
- 2022-01.jpg
- 2023-01.jpg
- 2024-01.jpg
